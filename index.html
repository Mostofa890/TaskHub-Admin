Ad Networks & Custom Code
⚙️ Custom Ad Code System: যেকোনো network-এর জন্য নিজের JavaScript কোড লিখুন। User App-এ resolve() / adResolve() call → Ad সফল। reject('msg') / adReject('msg') call → Ad fail। Promise return করলেও auto-detect হবে (90s timeout)।
Custom Code Examples
Example 1 — Monetag Pop-up
window.show_11878844('pop')
  .then(() => resolve())
  .catch(() => reject('Ad closed'));
Example 2 — Adsgram
const ctrl = Adsgram.init({ blockId: '23393' });
const res = await ctrl.show();
if (res && res.done) resolve();
else reject('Closed');
Example 3 — Any Custom Popup
// Load your own SDK
const s = document.createElement('script');
s.src = 'https://your-ad-network.com/sdk.js';
document.head.appendChild(s);
s.onload = () => {
  window.MyAdNet.show()
    .then(() => resolve())
    .catch(() => reject('Closed'));
};
Custom Code দিলে সেটি সবসময় Network-এর চেয়ে অগ্রাধিকার পাবে। Network field শুধু fallback হিসেবে রাখা হয়।
